Este projeto reproduz demonstrativos fiscais oficiais da União usando apenas dados públicos e código aberto. Os números batem com o que a União publica no Diário Oficial — e a conta está aberta para conferência.

Os cinco demonstrativos

Cada página traz os critérios normativos em linguagem natural, o código que os executa e a conferência contra o valor publicado. Não é preciso instalar nada nem saber programar.

  • Resultado previdenciário RREO Anexo 4 O déficit do RGPS, a previdência dos trabalhadores privados gerida pelo INSS.
  • Receita Corrente Líquida RREO Anexo 3 A régua contra a qual se medem quase todos os limites da LRF, com cada dedução explicada.
  • Despesa com saúde RREO Anexo 12 Se a União aplicou o mínimo constitucional em ações e serviços públicos de saúde.
  • Despesa com pessoal RGF Anexo 1 Quanto a União gasta com folha, com as regras de inclusão e exclusão abertas uma a uma.
  • Pessoal por elemento RREO Tabela 2 O detalhamento da folha por tipo de despesa, com a separação entre civis e militares.

Como isso funciona

Dado público, só

As bases vêm do Siga Brasil (Senado) e da SOF, e estão versionadas junto do código — o cálculo pode ser refeito daqui a anos com os mesmos números.

Critério antes do código

Cada regra do Manual de Demonstrativos Fiscais aparece escrita em português logo antes da linha de código que a executa. É literate programming aplicado à contabilidade pública.

Conferência no fim

Todo documento termina comparando o valor calculado com o publicado no Diário Oficial. Se divergir, aparece.

Para executar por conta própria: basta R (≥ 4.1) e Quarto, e rodar quarto render standalones/. Nenhuma credencial é necessária. O código está no repositório no GitHub.

Projeto experimental. Esta é uma prova de conceito de transparência fiscal, em caráter exploratório. A fonte oficial continua sendo o que a União publica no Diário Oficial.
